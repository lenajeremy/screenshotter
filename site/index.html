claude mcp add screenshotter --scope user -- \
  /Applications/Screenshotter.app/Contents/MacOS/Screenshotter mcp
codex mcp add screenshotter -- \
  /Applications/Screenshotter.app/Contents/MacOS/Screenshotter mcp

Then add tool_timeout_sec = 600 under [mcp_servers.screenshotter] in ~/.codex/config.toml, so videos have time.

// ~/.config/opencode/opencode.json, inside "mcp"
"screenshotter": {
  "type": "local",
  "command": [
    "/Applications/Screenshotter.app/Contents/MacOS/Screenshotter",
    "mcp"
  ]

Questions.Answered.

What does it need?

A Mac with Apple silicon on macOS 14 or later, and Chrome, Edge, Brave or Arc, which it uses to draw designs. Everything else is inside the app.

Does Ask AI need an API key?

Not if Claude Code or Codex is signed in on your Mac. An Anthropic API key works too.

How do updates work?

It checks once a day and installs a new version in one click. Every update is signed and notarized by Apple.

Can I build it from source? 
npm install && npm run app:build && open build/Screenshotter.app

The app’s ffmpeg is GPL; its source is beside each release: ffmpeg, x264, libvpx, Opus.
